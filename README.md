# esp32-smart-thermal-ventilation
ESP32-based smart thermal ventilation and monitoring system for electric vehicle applications using DHT22, OLED display, servo actuator, and LED bar visualization.
## Simulation Environment

This project was developed and tested using:

- Wokwi Simulator
- Visual Studio Code (VS Code)
- PlatformIO Extension

The simulation environment was used to create a digital twin prototype of an ESP32-based smart thermal ventilation system for electric vehicle applications.

---

## Components Used

### Main Components
- ESP32 DevKit V1
- DHT22 Temperature Sensor
- SG90 Servo Motor
- SSD1306 OLED Display (I2C)
- 10 Segment LED Bar Graph
- 220Ω Resistors

---

## System Features

- Real-time temperature monitoring
- Automatic ventilation control using servo actuator
- LED bar thermal level visualization
- OLED live status display
- Embedded thermal management simulation

---

## Simulation Purpose

This simulation demonstrates how an embedded thermal monitoring and automatic ventilation system can be applied in electric vehicle or Formula-style vehicle environments to improve thermal management and airflow control.
